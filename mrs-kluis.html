MRS-AUTH Handtekening
Deel I · 19A + 9B · v3.1 Lokaal
Genereer een MRS-AUTH handtekening via het 19A + 9B systeem. Het paar (A, B) wordt lokaal in de browser berekend zodat 19A + 9B = N, met de Triangle Requirement: dr(B) = dr(2·dr(A)). Na gebruik worden A en B onmiddellijk uit het geheugen gewist (zeroize).
✓ Handtekening berekend — sleutel gewist
EUF-CMA Tijdcode
Deel III · Forward Secrecy · v3.0
Genereer een tijdgebonden authenticatiecode op basis van HMAC-SHA256. De HMAC-sleutel is afgeleid van de kamersleutel (encSleutel). Alleen gebruikers in dezelfde kamer kunnen dezelfde code reproduceren.
✓ Tijdcode gegenereerd — kamersleutel gebonden
Bericht versleutelen
Deel IV · AES-256-GCM
Versleutel een bericht lokaal met AES-256-GCM. Het wachtwoord wordt via de MRS Clock KDF omgezet naar een 256-bit sleutel. Elk bericht krijgt een unieke 96-bit nonce.
✓ Versleuteld — nonce ingebakken in ciphertext
Bericht ontsleutelen
Deel IV · AES-256-GCM
Ontsleutel een eerder versleuteld bericht. De nonce zit ingebakken in de eerste 12 bytes van de ciphertext (base64).
✓ Ontsleuteld — sleutel gewist uit geheugen
🔐 Over MRS-AUTH
Onderzoeksfase · 2026
MRS-AUTH (Multiple Representation Systems Authentication) is een cryptografisch protocol van Bilal el Issaoui gebaseerd op N = 19A + 9B. Het biedt informatie-theoretische ontkenbaarheid.
Wiskundige basis
N = 19A + 9B
ggd(19,9)=1 → elke N>143 representeerbaar. Frobenius getal g(19,9)=143.
Sleutelafleiding
Clock KDF
Branchless, bijectief, auditbaar. Gebaseerd op de (19,9) structuur.
Deniability
Adv_DENY(A) = 0
Informatie-theoretisch bewijs. Onbegrensde adversary kan ware keten niet onderscheiden.
Auteur / status
Bilal el Issaoui · 2026
Onafhankelijk onderzoeker · Amsterdam.
